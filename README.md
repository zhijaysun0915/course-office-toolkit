# 🏢 辦公室 Excel 萬能工具箱 (Universal Office Excel Toolkit)

> **專為行政辦公室、專案團隊、各類機關機構與企業辦公室打造的「跨格式 Excel 自動化與移動辦公平台」**  
> 🏷️ **最新版本：v1.2.0 (2026.11 最新發布)** ｜ 📖 **[官方完整圖解手冊 (可另存 PDF)](https://zhijaysun0915.github.io/course-office-toolkit/manual.html)**  
> 參考現代辦公室行政實務與 [Wand.Tools](https://wand.tools/zh-TW/) 設計。  
> 採 **100% 純前端無伺服器架構 (Zero-Backend)**，所有文件、名冊與資產資料皆在瀏覽器本機內運算，**安全不外流**，同時支援 **Google Drive 雲端匯入與跨地移動辦公（在家 / 辦公室 / 差旅）**。

## 🛠️ 二、五大核心功能模組操作指南

### 1. 📊 雙 Excel 智慧比對器
- **解決痛點**：版本初稿 vs 最終定稿、新舊名冊、出缺勤比對、庫存盤點表人工逐格核對耗時易錯。
- **使用步驟**：
  1. 在左（基準檔 A）、右（最新檔 B）拖曳上傳 `.xlsx` / `.xls` / `.csv` 檔案，或直接在下方貼上 **Google 試算表 (Google Sheets) 連結**點擊「雲端匯入」。
  2. 選擇 **「🔑 對齊主鍵欄位」**（例如：`項目編號`、`工號`、`代碼`、`姓名`）。
  3. 點擊 **「🔍 立即執行比對」**，系統自動標示：
     - 🟢 **新增項目**（綠底）
     - 🔴 **已刪除 / 移除項目**（紅底刪除線）
     - 🟡 **欄位內容異動**（黃底高亮顯示 `原值 ➔ 新值`）
  4. 支援關鍵字即時搜尋，點擊統計小卡可快速篩選，並可點擊 **「📥 匯出差異報告 Excel」** 下載完整比對結果。

### 2. 📋 網頁 / Word / 公文資料搬移器
- **解決痛點**：從系統網頁、Word 表格、Email 或公文複製貼到 Excel 時格式跑掉，或帶有隱藏空白 (`CHAR(160)`) 導致 `VLOOKUP` / `XLOOKUP` 永遠對不到。
- **使用步驟**：
  1. 從網頁或 Word 複製表格或公文段落（如 `申請人：陳建宏 | 專案代碼：CS1001...`），直接按 `Ctrl+V` 貼入左側區域，或直接上傳 `.docx` Word 檔。
  2. 系統自動清理隱藏換行、不換行空白與全形英數字，並即時在右側轉換為結構化表格（可點擊任一儲存格直接微調修改）。
  3. 可一鍵 **「📥 匯出成乾淨 Excel (.xlsx)」**，或點擊 **「➡️ 送入比對器【檔案 A / B】」** 直接與另一份資料比對。

### 3. 🏢 辦公室例行事務工作台（排程衝突・工時統計・資產盤點）
- **🚨 場地/會議室與人員排程衝突檢測**：
  - 自動解析時段代碼（如 `一234`、`二345` 拆解為個別時段），秒抓出**同一時段同會議室/場地重複排定**或**同一人員同時段兩項工作**的衝突清單，並自動聚合節次（如：`星期一 第 2、3、4 節`）。
- **👨‍💼 人員工時 / 任務工時與加班津貼自動核算**：
  - 依職級標準時數與減免時數，自動加總各人員全期總工時並核算「超時/加班工時」或「未達時數」。
- **🧰 辦公室資產設備檢查 & 行政工具/用品盤點**：
  - 管理辦公設備、會議器材、行政用具與文具耗材，支援實盤數量即時修改、缺件警示與清冊匯出。

### 4. 🪄 Excel 萬能公式與清洗魔杖（參考 Wand.Tools）
- 不必背複雜函數！選擇辦公室情境（跨表查找 `XLOOKUP`、名單核對 `COUNTIF`、條件加總 `SUMIFS`、字串串接 `TEXTJOIN`、清除隱藏空白 `CLEAN`）並輸入欄位代號，即可一鍵生成並複製公式。

### 5. ☁️ 跨地移動辦公（在家 / 辦公室 / 差旅無縫接續）
- **Google 試算表直接 Import**：將 Google Sheets 分享權限設為「知道連結的任何人可檢視」，貼上連結即可跨地點直接抓最新資料。
- **工作台雲端快照 (`.json`)**：在辦公室做到一半要換電腦？點擊右上角 **「💾 匯出進度至 Google Drive」** 存進雲端硬碟；回到家點擊 **「📂 從 Google Drive 載入進度」**，所有比對結果、排程與盤點資料立即 100% 還原！

## 🤖 三、如何在您自己的 Gemini / Antigravity 中客製化改裝本專案？

本專案特別採用 **無框架、高可讀性的模組化結構**，讓任何辦公室同仁都能把專案放進自己的 **Google Antigravity IDE** 或 **Gemini** 中，用白話文請 AI 幫您客製化成貴單位專屬版本！

### 步驟 1：將專案下載到您的 Antigravity 工作區 (Workspace)

在 Antigravity 或電腦終端機執行：

```bash
git clone https://github.com/zhijaysun0915/course-office-toolkit.git
cd course-office-toolkit
```

然後在 Antigravity 將 `course-office-toolkit` 資料夾設為您的 **Active Workspace**。

### 步驟 2：認識專案檔案結構（AI 修改導引地圖）

| 檔案路徑 | 職責說明 | 您最常請 AI 修改的地方 |
| :--- | :--- | :--- |
| `index.html` | 網頁主介面、五大頁籤與彈窗 HTML | 修改系統標題、單位名稱、新增表單欄位或新功能頁籤 |
| `js/app.js` | 核心處理引擎（比對、擷取、衝突檢測、工時核算、雲端同步） | 修改**標準工時規則** (`baseHoursRule`)、調整**時段格式解析** (`expandTimeSlots`)、自訂匯出報表格式 |
| `js/demo-data.js` | 預設範例資料與常用 Excel 公式庫 | 替換為貴單位的預設排程範例、新增單位常用的 Excel 公式範本 |
| `css/style.css` | 視覺樣式、差異高亮配色與手機 RWD 排版 | 更換企業/機關代表色、調整表格字體大小 |
| `google-apps-script/Code.gs` | Google Drive 私人雲端雙向同步腳本 | 部署至個人 Google Apps Script，實現免公開連結的私人雲端存檔 |
| `辦公室萬能工具箱_移動辦公單一檔.html` | 將 HTML + CSS + JS 合一的免安裝單一檔 | 修改完程式碼後，可請 AI 重新打包此檔案放進 Google Drive |

### 步驟 3：直接複製以下 Prompt（提示詞）貼給您的 Gemini / Antigravity

您可以直接複製下方指令給您的 AI 助手：

1. **🔧 修改貴單位的「人員標準工時或加班規則」**：
   > 「請幫我修改 `js/app.js` 裡的 `baseHoursRule`：我們單位的標準工作時數是主管 8 小時、工程師 8 小時、約聘 6 小時、專案顧問 4 小時，並請幫我加上『兼任人員』類別。」

2. **🔧 適配貴單位內部系統匯出的 Excel 欄位名稱**：
   > 「我們單位系統匯出的 Excel 欄位名稱叫做『專案代號、任務名稱、負責人、排定時段、執行地點、預估工時』，請幫我調整 `js/app.js` 與 `js/demo-data.js` 讓衝突檢測與工時核算直接支援這些欄位名稱。」

3. **🔧 修改時段的編碼格式（例如 `1-234` 或 `Mon 2,3,4`）**：
   > 「我們單位的會議時段欄位格式是像 `102,103,104`（百位數代表星期一，後兩位代表時段），請幫我修改 `js/app.js` 的 `expandTimeSlots` 函數來正確解析衝突。」

4. **🔧 新增部門專屬的例行業務頁籤**：
   > 「請幫我在左側選單與主畫面新增一個『專案里程碑完成進度追蹤』頁籤，可以匯入全公司專案 Excel，自動篩選出『尚未完成』的項目清單，並產生提醒 Email 範本。」

5. **🔧 將修改後的版本重新打包成「單一 HTML 隨身檔」**：
   > 「請幫我將目前修改好的 `index.html`、`css/style.css`、`js/demo-data.js` 與 `js/app.js` 重新合併產出最新的 `辦公室萬能工具箱_移動辦公單一檔.html`。」
